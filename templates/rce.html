Critical Severity Remote Code Execution

💻 OS Command Injection Playground

Command injection occurs when an application passes unsafe user-supplied data to a system shell (subprocess.Popen(..., shell=True) or os.system()). This allows an attacker to execute arbitrary operating system commands with server privileges.

🛡️ Vulnerable vs. Secure Implementation

❌ VULNERABLE CODE (app.py): 
# Invokes a system shell with unsanitized user string
cmd = f"ping -n 1 {target}"
output = subprocess.check_output(cmd, shell=True)
✅ SECURE REMEDIATION: 
# 1. Disable shell=True and pass command as arguments list
# 2. Validate with ipaddress module
import ipaddress
ipaddress.ip_address(target) # Ensures valid IP only
subprocess.check_output(["ping", "-n", "1", target], shell=False)
