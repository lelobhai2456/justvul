📋 Pastejacking & Clipboard Hijacking

Demonstration of how what is visually displayed on a web page can be completely different from what gets copied into your system clipboard. If an unsuspecting user pastes the copied text into a terminal, it can instantly execute arbitrary commands!

⚡ Technique 1: JavaScript Event Interception

JS Event Listener

Malicious JavaScript intercepts the browser's copy event and replaces the clipboard content with an attacker-crafted command containing an auto-executing newline.

WHAT YOU SEE ON SCREEN: Harmless Shell Command
git clone https://github.com/torvalds/linux.git
Tip: Highlight the text above and press Ctrl + C, or click the button below.
Injected Hidden Payload:
echo "ALERT: PASTEJACKING ATTACK TRIGGERED!" && calc.exe\n

🎨 Technique 2: CSS DOM Stealth Injection

No JS Required!

Even if JavaScript is completely disabled, CSS can hide malicious text off-screen (position: absolute; left: -9999px;). When you select the line and copy, the browser includes the off-screen text!

WHAT YOU SEE ON SCREEN: echo "Updating System..."
echo "Updating System..." ; powershell.exe -Command "Start-Process calc.exe" #
Tip: Highlight the box above with your mouse and press Ctrl + C.
What your clipboard actually gets:
echo "Updating System..." ; powershell.exe -Command "Start-Process calc.exe" #

            🛡️ How Pastejacking Works & How to Protect Yourself
        


        

            

                
Why is Pastejacking so dangerous?

                

                    Developers, sysadmins, and students often copy commands directly from documentation, StackOverflow, or blogs into their command prompt (PowerShell, Bash, Command Prompt).
                

                

                    By appending a newline character (\n or \r\n), the terminal interprets it as pressing the Enter key immediately. The malicious command begins executing before the human eye can even register what was pasted!
                

            


            

                
Best Defense Practices

                
    
                    
  • Paste into Notepad first: Always paste commands into a simple text editor before pasting into a terminal with elevated privileges.
    • 
                    
  • Terminal Safe-Paste feature: Modern terminals (like Windows Terminal or iTerm2) have "bracketed paste mode" which warns when pasting multi-line or newline-containing strings.
    • 
                    
  • Avoid blind execution: Never run piped scripts like curl | bash directly from untrusted sources.
    •
