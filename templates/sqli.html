🛡️ Vulnerable vs. Secure Implementation

❌ VULNERABLE CODE (app.py): 
# Direct string concatenation allows input to alter query syntax
cursor.execute(f"SELECT * FROM users WHERE username = '{username}' AND password = '{password}'")
✅ SECURE REMEDIATION (Parameterized Queries): 
# Use placeholders (?) so user input is strictly treated as data
cursor.execute("SELECT * FROM users WHERE username = ? AND password = ?", (username, password))
