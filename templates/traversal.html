🛡️ Vulnerable vs. Secure Implementation

❌ VULNERABLE CODE (app.py): 
# Direct concatenation allows '../' traversal sequences
target = os.path.join(SAMPLE_DIR, filename)
with open(target, 'r') as f:
    return f.read()
✅ SECURE REMEDIATION: 
# 1. Use werkzeug.utils.secure_filename() or
# 2. Canonicalize path and ensure it stays inside base dir:
canonical = os.path.realpath(os.path.join(SAMPLE_DIR, filename))
if not canonical.startswith(os.path.realpath(SAMPLE_DIR)):
    raise PermissionError("Access Denied: Path Traversal Attempt")
