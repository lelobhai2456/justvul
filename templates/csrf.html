🎭 Cross-Site Request Forgery (CSRF)

CSRF tricks a victim into executing unwanted actions on a web application in which they're currently authenticated. Because browsers automatically send session cookies with cross-site requests, a malicious website can trigger sensitive actions (password change, fund transfer) without user consent!

🛡️ How to Prevent CSRF

1. Anti-CSRF Tokens: Generate a cryptographically random, unpredictable token tied to the user's session (e.g. Flask-WTF / Synchronizer Token Pattern) and validate it on every state-changing request.

2. SameSite Cookie Flag: Set cookie attributes to SameSite=Lax or SameSite=Strict to prevent ambient cookie submission from cross-origin requests.
